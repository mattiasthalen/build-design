## The writing pass

A skill lands through `writing-for-agents` (`mattpocock/skills`). It runs on a
new `SKILL.md` and on an edit to one. Write the change first; the pass sharpens
prose that already says the right thing.

The pass is done when every line it flags is either changed or has its reason
for standing written into the skill's `README.md`. That file pairs each rule
with the incident that earned it, so a line that survives on judgement alone
still says whose judgement, and on what.
